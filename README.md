# AptitudeX

A responsive, vanilla HTML/CSS/JavaScript aptitude preparation platform for placement and competitive-exam practice.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server. No API key is required.

## Contents

- 2,000 AptitudeX questions across 50 topics
- 4,746 imported objective questions from the supplied R.S. Aggarwal source PDF
- Solved examples with numbered mathematical steps
- Practice mode with answers hidden until submission
- Formula handbook, mock tests, PDF library, progress tracking, and search

The application is fully client-side and uses only HTML, CSS, and vanilla JavaScript.
